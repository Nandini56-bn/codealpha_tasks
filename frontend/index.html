About This Project

AI Music Generation with Virtual Cartoon Band

This project uses Machine Learning (LSTM), Gemini AI, and Lyria to create music, and a virtual cartoon band brings the music to life with stunning animations and performances.

1. Local LSTM MIDI

CodeAlpha Task 3: Trained PyTorch 2-layer LSTM on Bach MIDI sequences. Generates genuine polyphonic .mid files.

2. Gemini Assistant

Interprets natural language (English, Telugu, Hinglish) into structured MusicSpec requirements and composes original lyrics.

3. Lyria 3.5 Audio

Calls Google Lyria 3.5 API to generate full stereo AI songs for modern genres (Mass, EDM, Lo-fi, Rock, etc.).

4. Virtual Cartoon Band

8 original cartoon musicians dynamically perform and sway to the music using Web Audio API energy analysis.
