📖 How the AI Music Generation Pipeline Works

1. Public Domain MIDI Dataset

Extracted 50 public-domain classical compositions (J.S. Bach Chorales) directly from music21.corpus. No copyrighted commercial songs were used.

2. Note Parsing with music21

Extracted 14,868 pitches, polyphonic chords, and rests into discrete string tokens (e.g. 'C4', '0.4.7', 'REST'), building a 51-token vocabulary.

3. PyTorch 2-Layer LSTM Model

Trained locally on 14,836 sequence patterns ($N=32$) over 15 epochs, bringing training loss down to 0.86. Uses Softmax Temperature ($T$) sampling for creativity control.

4. Web Audio Synthesis & Band Sync

Generated sequence is written to a .mid file, downloaded, and parsed in the browser via Tone.js & @tonejs/midi, triggering real-time note callbacks to animate the cartoon band!
